\chapter{Estructuras de Datos}

\section{Union Find / Disjoint Set Union (DSU)}

El \textbf{Union-Find}  es una estructura de datos que permite mantener un conjunto de elementos particionados en subconjuntos disjuntos. Es muy eficiente para operaciones de conectividad, ya que nos dice si dos elementos pertenecen al mismo grupo y nos permite unirlos. Se basa en dos operaciones principales:
\begin{itemize}
    \item \texttt{find(x)}: Sirve para saber a qué conjunto pertenece el elemento $x$. Devuelve el "representante" (o raíz) de ese conjunto.
    \item \texttt{unite(a, b)} o \texttt{union(a, b)}: Une los conjuntos a los que pertenecen $a$ y $b$.
\end{itemize}

\textbf{Uso en grillas 2D} \\
El Union-Find está diseñado para trabajar con estructuras en una sola dimensión (1D), es decir, maneja elementos como si fueran posiciones en un arreglo lineal ($0, 1, 2, \dots, N-1$). Por eso, cuando el problema es en 2D, como una grilla de filas y columnas $(r, c)$, primero hay que convertir cada celda en un único número para poder usar DSU correctamente. 

Esto se hace con la siguiente fórmula:
\[ id = r \times m + c \]
(Donde $m$ es la cantidad de columnas de la grilla). 

\begin{lstlisting}[language=C++]
struct DSU {
    vector<int> parent;
    vector<int> sz; // Tamano del componente

    DSU(int n) {
        parent.resize(n + 1);
        sz.assign(n + 1, 1);
        for (int i = 0; i <= n; i++) parent[i] = i;
    }

    // Encuentra el representante con Compresion de Caminos
    int find(int i) {
        if (parent[i] == i) return i;
        return parent[i] = find(parent[i]);
    }

    // Une dos conjuntos por Tamano
    void unite(int i, int j) {
        int root_i = find(i);
        int root_j = find(j);
        if (root_i != root_j) {
            if (sz[root_i] < sz[root_j]) swap(root_i, root_j);
            parent[root_j] = root_i;
            sz[root_i] += sz[root_j];
        }
    }

    bool same(int i, int j) {
        return find(i) == find(j);
    }
};
\end{lstlisting}

\section{Fenwick Tree (BIT)}

El \textbf{Fenwick Tree} o \textbf{Binary Indexed Tree (BIT)} es una estructura de datos sobre un arreglo de números que permite mantener información acumulada y responder consultas de forma eficiente.

Se usa principalmente para dos operaciones:
\begin{itemize}
    \item \textbf{Actualización de punto}: sumar un valor a una posición específica.
    \item \textbf{Consulta de prefijo}: obtener la suma de los elementos desde la posición $1$ hasta $i$.
\end{itemize}

\textbf{Complejidad temporal}
\begin{itemize}
    \item \texttt{update}: $O(\log n)$
    \item \texttt{query}: $O(\log n)$
\end{itemize}

\textbf{Complejidad espacial}: $O(n)$.

\textbf{Idea principal} \\
Cada posición del BIT guarda la suma de un bloque de elementos del arreglo original. Gracias a esto, para actualizar o consultar no es necesario recorrer todo el arreglo: solo se visitan algunos nodos relacionados con el bit menos significativo de cada índice.

\textbf{Función \texttt{update(idx, val)}}

Sirve para sumar \texttt{val} en la posición \texttt{idx}.

En la práctica, el arreglo del BIT y el tamaño \texttt{n} suelen declararse como variables globales o como atributos de una estructura/clase, porque las funciones \texttt{update} y \texttt{query} necesitan acceder a ellos. No es obligatorio que sean globales: también se pueden pasar como parámetros o encapsular dentro de un \texttt{struct}, pero en programación competitiva se usa mucho la versión global por simplicidad.

\begin{itemize}
    \item \textbf{Cómo funciona}: empieza en \texttt{idx} y va subiendo hacia sus "padres" en la estructura, agregando el valor en cada bloque afectado.
    \item \textbf{Importante}: este BIT normalmente trabaja con índices desde $1$ hasta $n$.
\end{itemize}

\begin{lstlisting}[language=C++]
void update(int idx, int val) {
    for (; idx <= n; idx += idx & -idx)
        bit[idx] += val;
}
\end{lstlisting}

\textbf{Función \texttt{query(idx)}}

Calcula la suma de los elementos desde la posición $1$ hasta \texttt{idx}.

\begin{itemize}
    \item \textbf{Cómo funciona}: suma el valor en \texttt{idx} y luego retrocede eliminando el bit menos significativo hasta llegar a cero.
\end{itemize}

\begin{lstlisting}[language=C++]
int query(int pos) {
    int res = 0;
    for (; pos > 0; pos -= pos & -pos)
        res += bit[pos];
    return res;
}
\end{lstlisting}

Para obtener la suma de un rango $[L, R]$, se usa:
\[
query(R) - query(L - 1)
\]

\textbf{¿En qué tipos de problemas sirve?}

El BIT es útil cuando necesitas una mezcla de consultas y modificaciones en tiempo real, sobre todo si ambas afectan un solo punto del arreglo.

\begin{itemize}
    \item \textbf{Cálculo de inversiones}: contar pares $(i, j)$ tales que $i < j$ y $A[i] > A[j]$.
    \item \textbf{Actualizaciones de punto y consultas de rango}: cuando el arreglo cambia constantemente y necesitas responder sumas rápidas.
    \item \textbf{Conteo de frecuencias}: mantener cuántas veces aparece cada valor para responder consultas sobre prefijos o rangos de frecuencias.
\end{itemize}

\textbf{Observación} \\
Si el problema requiere actualizaciones en un rango completo o consultas más complejas, a veces conviene usar un segment tree; si solo necesitas sumas de prefijos con cambios puntuales, el Fenwick Tree suele ser más simple y rápido de implementar.
